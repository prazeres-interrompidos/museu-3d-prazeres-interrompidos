MUSEU VIRTUAL DOS LIVROS Prazeres Interrompidos

Como visitar

Computador: Use apenas as teclas de direção ← ↑ → ↓ para caminhar. Arraste o rato para olhar.

Telemóvel: use o joystick no canto inferior esquerdo para caminhar (para cima = avançar; para baixo = recuar) e arraste o dedo no espaço principal para olhar.

Aproxime-se de uma capa e toque/clique nela para ver os dados do episódio e ouvir o áudio.
